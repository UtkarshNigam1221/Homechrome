# Inventory Lambda - User Flows

## Overview
This document describes the user flows for the Inventory Lambda service, covering stock management, inventory tracking, and transaction history.

## State Diagram - Inventory Transaction Types

```
                    ┌─────────────────┐
                    │   ADD STOCK     │
                    │ (Increase qty)  │
                    └────────┬────────┘
                             │
              ┌──────────────┼──────────────┐
              │              │              │
              ▼              ▼              ▼
     ┌─────────────┐ ┌─────────────┐ ┌─────────────┐
     │  Purchase   │ │  Return     │ │  Adjustment │
     │  Order      │ │  from       │ │  (Positive) │
     │             │ │  Customer   │ │             │
     └─────────────┘ └─────────────┘ └─────────────┘

                    ┌─────────────────┐
                    │  REMOVE STOCK   │
                    │ (Decrease qty)  │
                    └────────┬────────┘
                             │
       ┌─────────────────────┼─────────────────────┐
       │              │              │              │
       ▼              ▼              ▼              ▼
┌───────────┐ ┌───────────┐ ┌───────────┐ ┌───────────┐
│  Order    │ │  Damaged  │ │  Lost     │ │ Adjustment│
│  Shipped  │ │           │ │           │ │ (Negative)│
└───────────┘ └───────────┘ └───────────┘ └───────────┘

                    ┌─────────────────┐
                    │    RESERVE      │
                    │ (Hold for order)│
                    └────────┬────────┘
                             │
              ┌──────────────┴──────────────┐
              │                             │
              ▼                             ▼
     ┌─────────────────┐          ┌─────────────────┐
     │  Order Created  │          │  Order Cancelled│
     │  (qty reserved) │          │  (qty released) │
     └─────────────────┘          └─────────────────┘
```
