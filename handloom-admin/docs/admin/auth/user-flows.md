# Auth Lambda - User Flows

## Overview
This document describes the user flows for the Authentication Lambda service.

         │

└─────────────────┘     └────────┬────────┘
                                 │
                    ┌────────────┴────────────┐
                    │                         │
                    ▼                         ▼
           ┌───────────────┐         ┌───────────────┐
           │   VALID       │         │   INVALID     │
