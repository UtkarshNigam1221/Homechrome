# Auth Lambda - Sequence Diagrams

## Overview
This document contains sequence diagrams for all authentication flows.

---

## 1. Login Sequence

```
┌────────┐          ┌─────────┐          ┌─────────────┐          ┌──────────┐          ┌──────────┐
│ Client │          │ API GW  │          │ Auth Lambda │          │ DynamoDB │          │   JWT    │
└───┬────┘          └────┬────┘          └──────┬──────┘          └────┬─────┘          └────┬─────┘
    │                    │                      │                      │                     │
    │ POST /auth/login   │                      │                      │                     │
    │ {email, password}  │                      │                      │                     │
    │───────────────────▶│                      │                      │                     │
    │                    │                      │                      │                     │
    │                    │  Forward request     │                      │                     │
    │                    │─────────────────────▶│                      │                     │
    │                    │                      │                      │                     │
    │                    │                      │  GetItem(email)      │                     │
    │                    │                      │─────────────────────▶│                     │
    │                    │                      │                      │                     │
    │                    │                      │  User record         │                     │
    │                    │                      │◀─────────────────────│                     │
    │                    │                      │                      │                     │
    │                    │                      │  Verify password     │                     │
    │                    │                      │──────────┐           │                     │
    │                    │                      │          │           │                     │
    │                    │                      │◀─────────┘           │                     │
    │                    │                      │                      │                     │
    │                    │                      │  Generate tokens     │                     │
    │                    │                      │─────────────────────────────────────────▶│
    │                    │                      │                      │                     │
    │                    │                      │  access_token,       │                     │
    │                    │                      │  refresh_token       │                     │
    │                    │                      │◀─────────────────────────────────────────│
    │                    │                      │                      │                     │
    │                    │                      │  Store refresh token │                     │
    │                    │                      │─────────────────────▶│                     │
    │                    │                      │                      │                     │
    │                    │  {tokens, user}      │                      │                     │
    │                    │◀─────────────────────│                      │                     │
    │                    │                      │                      │                     │
    │ 200 OK             │                      │                      │                     │
    │ {tokens, user}     │                      │                      │                     │
    │◀───────────────────│                      │                      │                     │
    │                    │                      │                      │                     │
```

## 3. Token Refresh Sequence

```
┌────────┐          ┌─────────┐          ┌─────────────┐          ┌──────────┐          ┌──────────┐
│ Client │          │ API GW  │          │ Auth Lambda │          │ DynamoDB │          │   JWT    │
└───┬────┘          └────┬────┘          └──────┬──────┘          └────┬─────┘          └────┬─────┘
    │                    │                      │                      │                     │
    │ POST /auth/refresh │                      │                      │                     │
    │ {refresh_token}    │                      │                      │                     │
    │───────────────────▶│                      │                      │                     │
    │                    │                      │                      │                     │
    │                    │  Forward request     │                      │                     │
    │                    │─────────────────────▶│                      │                     │
    │                    │                      │                      │                     │
    │                    │                      │  Verify refresh token│                     │
    │                    │                      │─────────────────────────────────────────▶│
    │                    │                      │                      │                     │
    │                    │                      │  Token valid, claims │                     │
    │                    │                      │◀─────────────────────────────────────────│
    │                    │                      │                      │                     │
    │                    │                      │  Check token in DB   │                     │
    │                    │                      │  (not revoked)       │                     │
    │                    │                      │─────────────────────▶│                     │
    │                    │                      │                      │                     │
    │                    │                      │  Token exists        │                     │
    │                    │                      │◀─────────────────────│                     │
    │                    │                      │                      │                     │
    │                    │                      │  Generate new tokens │                     │
    │                    │                      │─────────────────────────────────────────▶│
    │                    │                      │                      │                     │
    │                    │                      │  new access_token,   │                     │
    │                    │                      │  new refresh_token   │                     │
    │                    │                      │◀─────────────────────────────────────────│
    │                    │                      │                      │                     │
    │                    │                      │  Update refresh token│                     │
    │                    │                      │─────────────────────▶│                     │
    │                    │                      │                      │                     │
    │                    │  {tokens}            │                      │                     │
    │                    │◀─────────────────────│                      │                     │
    │                    │                      │                      │                     │
    │ 200 OK {tokens}    │                      │                      │                     │
    │◀───────────────────│                      │                      │                     │
    │                    │                      │                      │                     │
```
