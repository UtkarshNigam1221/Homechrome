Catalog Rulebook

Filters, search results, and shipping charges are all built automatically from what you type. These 12 rules keep products findable and prices correct.

Part A

Categories

1A category is a type of product — never a size, fabric, or print

Sizes and fabrics are filters, not categories. Creating a new category should be rare.

Bedsheets · Dohars · Cushions
Bedsheet Cotton Casement King Size

2Clean name, plus a description and an image

No codes, no trailing spaces ("Bedsheets " ≠ "Bedsheets"). Description: 2–3 sentences about the range — Google reads it.

3Define the filters and their allowed options when creating the category

A filter only appears on the website if it's defined on the category. Only add filters where products actually differ.

Part B

Filter values on products

4Copy values from the option list — never type from memory

Spelling and capitals must match exactly. HANDLOOM, Handloom and handloom become three broken filters.

5Fill every filter on every product

A product with no "Craft" value disappears the moment a customer ticks any Craft box. Don't know the value? Find out before it goes live.

6One level of detail per filter

Rajasthan · Uttar Pradesh
India · Sanganer Rajasthan · UP (mixed levels)

Colours: record the dominant colour (Blue, Pink) — or if everything is "multicolour printed", have no colour filter at all.

Part C

Products

7Name = Size + Material + Type — Design code. Always unique.

King Size Cotton Casement Bedsheet — DBGWK 5104
DBGWK 5104 · six products all named the same

The name is the strongest search signal — a code-only name is invisible to someone searching "cotton bedsheet king size".

8Description: minimum four lines, never empty

  • Fabric — "100% cotton casement, 144 TC"
  • Size — inches/cm, which bed it fits
  • Contents — "1 bedsheet + 2 pillow covers"
  • Care — "machine wash, dark colours separately"

Search and "similar products" read this. Empty description = nobody finds it.

9Weight: real packed grams, never 0

Courier charge is calculated from this. Weight 0 = we pay the shipping difference. A double bedsheet ≈ 1200 g. If unsure, weigh it.

10At least 2 photos of the actual item, best one first

First photo shows in listings. Add a close-up of the weave/print.

11MRP above selling price, both in rupees

The strike-through discount is calculated from these two.

12Stay Draft until the checklist passes

Draft = invisible to customers. Only Active products reach the live website.

Before switching to Active

Final checklist

The one habit that prevents most mistakes: never type a value you've typed before — copy it from an existing product or the option list.
